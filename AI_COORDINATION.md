## Rules
- Never directly commit experimental changes to main.
- Use feature branches.
- Do not overwrite another developer's work.
- Review changes before merging.
- Preserve working features.
- Never assume undocumented save fields exist.
- Back up saves before editing.
- Verify changes before declaring tasks complete.

## Workflow
1. Tasks are assigned through this file or GitHub issues.
2. Developers work on separate branches.
3. Changes are reviewed.
4. Build checks are run.
5. Approved changes are merged into main.
